Projects

Fine tuned Local LLM Model Project

Developing new SD2 model by training a base LLM Llama 3.2-3B multimodel with 3 billion datapoints using FineTome 100k dataset to fine-tune the model for efficient and accurate conversational ability in a local environment.

Using the base LLM Llama 3.2 trained with 3 billion sets of data, new datapoints were processed to fine-tune the model for a conversational accuracy percent error change of 12%. I ensured the new model, named SD2 after my initials, could run efficiently on my local laptop for response times of under 4 seconds. These responses specialize in providing a proper set of background information for the answers given. These answers were fine-tuned to provide accurate information on stocks and their exchange.

Local Spotify API App

Developed code utilizing Spotify API to allow users to retrieve their individual top listened artists based on specified time ranges. Created algorithms to allow users to create unique playlists based on their top listened artists or songs based on a long, short, or medium-range time frame.

Importing the spotify API for online account access, I developed code to retrieve an accounts top listened artists/songs from a long, short, or medium time frame. This can be retrieved by the user using specific function commands ensuring quick and simple retrieval for the user. I also developed algorithms to create a playlist inspired by the spotify "wrapped" playlist. This playlist algorithm allows the user to create a playlist based on many different top listened to artists or songs based on the long, short, or medium time frame. This allows users to make a unique playlist full of songs at any time.
